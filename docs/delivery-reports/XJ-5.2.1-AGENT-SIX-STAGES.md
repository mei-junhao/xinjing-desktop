## 现在的阶段状态

1. 聊天入口：已本地验证来源选择、预览、人工确认、真实受控调用、成功草稿回交及失败提示；六任务聊天气泡与刷新恢复均按三栏标题呈现，不暴露原始 JSON 字段。
2. 持久化与恢复：运行元数据不存正文；原问题和草稿位于独立本机集合，已纳入手动加密备份。恢复保留 ID、问题、编辑和采用状态，但重新核验来源、重新确认；不声称能续接已断开的模型流或从网络请求的半个 token 继续。
3. 六工作流：六条路径均经生产模块和真实 Electron 页面成功执行，输出为待人工审阅草稿。成功验收仅替换 AI.send 的外部模型返回，不代表真实模型临床质量已验证。
4. 证据草稿工作台：事实/推论/假设编辑、保存、人工采用、丢弃、来源跳回与历史均已验证。采用仅保存本机草稿，不自动写入正式会谈；新模型输出必须通过严格三栏和引用审核。旧本机纯文本草稿保留兼容读取，仅放入推论区，不伪装成事实。
5. 受控编排：固定 Context Builder、Intent Classifier、Supervision Router、Evidence Validator、Draft Orchestrator；复用现有 Bridge/Adapter/Runtime。不是自由互调的多 Agent，也没有六次独立模型调用。
6. 验收：当前源码候选同 SHA 的本地自动、Electron、视觉和双重评审均通过；正式版本放行未完成。不能称 release-ready、released 或全部六阶段正式放行。
